# KSSM Bahasa Melayu Learning Diagnostic System

A curriculum-aligned learning diagnostic system for KSSM Bahasa Melayu Tingkatan 1–5.

## Core principle

The system separates:

1. **MOE/DSKP curriculum data** — official curriculum structure and source-aligned standards.
2. **AI diagnostic metadata** — micro-skills, error tags, mastery estimates, misconceptions and remediation paths.
3. **Teacher judgement** — formal teacher-confirmed mastery / TP remains separate from AI suggestions.

## Target workflow

```text
Corrected physical exercise / test upload
→ question and marking recognition
→ curriculum mapping
→ error diagnosis
→ longitudinal student mastery profile
→ weakness detection
→ targeted remediation
→ later evidence verifies improvement
```
